# Budget-App
This will be the repo to store anything to do with creating a project for a budget app.

Overview
This is one of my first personal coding projects to create a simple budget app to track my fiances on a weekly basis.

Problem Statement
Need to automate tracking finances in order to stay on financial goals.

Solution
Budgeting App which tracks income, expenses on a weekly basis.

Features
 - Allow multiple income sources to be input and display them.
 - Allow for input and display of line items, how much they cost, and what week's expenses come out.
 - Add up expenses and display total expenses and money left.
 - Allow for categorization of expenses and indication of category based on the use, and accounts for each line item.
 - Identify based on categories the total in those categories and percentage.
 - Save budgets and templates which can be used as a base that can then be adjusted.

How to Run
Budget will be presented as a grid-like table where weeks are on top and line items are on the bottom. Income will be at the top, and then categories at the bottom.

1.App presents a grid.
2. Prompts to input income and sources.
3. Prompts to input line item.
4. Prompts to input costs at each week interval.
5. Option to input category.
6. App will colour code, indicate and update input and figures as they are input.
